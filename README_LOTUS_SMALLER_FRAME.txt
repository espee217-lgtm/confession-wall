Lotus Smaller Frame Patch

This patch only adjusts the visual scale of the Lotus Aura avatar frame through CSS variables.
It does not modify the Lotus spritesheet image, animation frames, JS, shop logic, backend, auth, payments, routes, or layouts.

Overwritten file:
- client/src/styles/cosmetic-animations.css

Scale changes:
- default: 0.26 -> 0.22
- nav: 0.16 -> 0.14
- post: 0.20 -> 0.17
- comment: 0.15 -> 0.13
- shop preview: 0.24 -> 0.20
- profile: 0.34 -> 0.29

This makes only the Lotus Aura frame smaller while keeping the avatar image, circular crop, and animation mechanics intact.
No npm install is required.

# Confession Wall Desktop Guidebook Patch

This patch adds a lightweight desktop Guidebook / Notice Board popup.

What it adds:
- Desktop-only Guidebook popup with tabs
- Reopen button on desktop
- Auto-open after the Home tutorial completes
- Versioned localStorage so future patch notes can appear again
- Compressed WebP desktop guide screenshots

No backend, auth, payment, shop purchase, database, or route logic is changed.
No npm install is needed.
